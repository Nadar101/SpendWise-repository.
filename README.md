
# SpendWise - Interactive Budget Tracker

## Project Description
SpendWise is a simple budgeting application that helps users record expenses and monitor their monthly budget.

## Improvements Made This Week
- Added interactive expense tracking.
- Added a monthly budget dashboard.
- Added automatic expense calculations.
- Added budget warnings.
- Added a list of expense records.

## JavaScript Concepts Used

### 1. Conditionals
If, else if, and else statements check whether the user is within or over budget.

### 2. Arrays
An array called expenses stores multiple expense records.

### 3. Loops
For loops calculate total expenses and display all records.

### 4. DOM Manipulation
The application updates the dashboard and expense list directly on the webpage.

### 5. Events
An event listener handles form submissions when users add expenses.

## Challenges and Solutions
One challenge was calculating total expenses and displaying them correctly. I solved this by using arrays and loops to process expense records.

SpendWise demonstrates how JavaScript can make a budgeting application interactive and user-friendly.
